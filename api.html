Trucs de cathos

API ouverte

Les rendez-vous de Trucs de cathos sont libres de réutilisation : application de prière, site de paroisse, écran d’accueil d’une église… Pas de clé, pas d’inscription. Merci simplement de citer « Trucs de cathos » et de garder le lien vers la page d’origine de chaque événement (champ u).

Les fichiers

Fichiers JSON statiques, mis à jour chaque semaine, lisibles depuis n’importe quel site (en-tête Access-Control-Allow-Origin: *).

  • https://trucsdecathos.fr/data/evenements.json : tous les événements à venir des diocèses (≈ 3 000, 2,6 Mo).
  • https://trucsdecathos.fr/data/dep/<code>.json : les mêmes, par département (03, 58, 2A…), beaucoup plus légers : à préférer dans une appli mobile.
  • https://trucsdecathos.fr/data/types.json : les 53 types d’événements (nom, famille) et les 8 familles (nom, couleur).
  • https://trucsdecathos.fr/data/messes/<code>.json : horaires des messes du département (source Messes Info), quand ils sont disponibles.
  • https://api.trucsafaire.fr/cathos/agenda : les événements proposés par les paroisses et les visiteurs, relus avant publication.

Un événement

{ "id": "dio-moulins-…", "t": "Veillée d’adoration", "type": "adoration",
  "s": "2026-11-20", "e": "", "h": "20:30", "hf": "22:00",
  "lieu": "Église Saint-Pierre", "w": "Moulins", "z": "03", "lat": 46.566, "lon": 3.333,
  "d": "Description courte…", "u": "https://…/page-d-origine", "org": "Diocèse de Moulins", "img": "https://…/affiche.jpg" }

s début et e fin (AAAA-MM-JJ), h et hf heures (HH:MM), w commune, z département. img n’existe que si l’organisateur a publié une affiche.

Exemple : ce qui se passe près de moi

const km = (a, b, c, d) => Math.hypot((d - b) * Math.cos((a + c) / 2 * Math.PI / 180) * 111.32, (c - a) * 110.57);
async function presDeMoi(lat, lon, dep, rayon = 20) {
  const ev = await fetch("https://trucsdecathos.fr/data/dep/" + dep + ".json").then(r => r.json());
  const auj = new Date().toISOString().slice(0, 10);
  return ev.filter(e => (e.e || e.s) >= auj && km(lat, lon, e.lat, e.lon) <= rayon);
}

Pour ouvrir un événement dans Trucs de cathos : https://trucsdecathos.fr/#e=<id>.
